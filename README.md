**Dart OOP & Async Demonstration**
A Dart console application demonstrating Object-Oriented Programming (OOP) combined with asynchronous programming using Future, async, and await.

Features
OOP Concepts: Abstract classes (Serviceable), mixins (GPS), inheritance (SportsCar, ElectricCar), and method overriding.

Asynchronous Operations: Uses Future.delayed to simulate non-blocking tasks like system diagnostics and battery charging.

How to run:
Dart SDK installed, OR

An online Dart runner like DartPad
